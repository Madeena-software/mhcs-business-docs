Member

Purpose: coordinate care and receive member-safe outcomes. Surface sequence: Messaging → On-site / Physical → Messaging notification → Temporary Result Surface when richer view/download is needed → Messaging. Boundary: no permanent Member account or portal.

Authorized B2B Representative

Purpose: coordinate an authorized business service scope. Surface: Messaging. Actions: confirm entitlement/member scope, service/site/date/shift, receive confirmation, request authorized changes, monitor applicable quota, understand no-show consequences, reconcile usage. Boundary: do not infer contract terms.

Site Staff overview

Purpose: deliver assigned site operations. Surface: Messaging → Temporary Site Workspace → On-site / Physical → Messaging. Boundary: Role → eligibility → assignment → authorized workspace; station selection does not elevate role.

Reception / Registration

Booking lookup → identity verification → eligibility/payment check → consent confirmation → check-in → ticket issuance. Handoff: Basic Examination or Radiography.

Basic Examination

Assigned Temporary Site Workspace → measurements/vitals/structured assessment → review and completion → Radiography handoff. Boundary: operational scope only.

Radiography

Messaging assignment → Temporary Site Workspace → claim → capture → review/retake if justified → submit → accepted/action-needed. Clinical repeat requests return through authorized dispatch.

Doctor overview

Purpose: produce authorized clinical output. Surface: Messaging → Temporary Clinical / DICOM Workspace → Messaging. Boundary: specialty, qualification, assignment, and modality eligibility remain explicit; no permanent worklist portal.

Radiologist

Case offer → review → usable/repeat_required → controlled clinical reason/note in the clinical workspace → linked Radiography repeat → replacement study → draft/finalize → result publication.

Authorized Specialist

Case offer → authorized specialty/service workspace → specialty-appropriate clinical output → Messaging. Radiology DICOM/quality/repeat steps apply only with independent authorization.

Global Admin / Super Admin

Persistent Admin Web → Site Staff roles/eligibility and assignments → Doctor authorization → site/service/business configuration → audit → refund/cash/B2B exceptions → payout suspension/resumption → identity/access exceptions.
