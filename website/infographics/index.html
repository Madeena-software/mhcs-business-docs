Text equivalent and semantic notes

MHCS coordinates external capabilities around the current examination / radiography / AI / optional Doctor Review slice. Messaging is the persistent interaction layer. Member, Authorized B2B Representative, Site Staff, and Doctor use the appropriate interaction surface; Global Admin uses one Persistent Admin Web. Examination-service completion does not automatically complete the broader healthcare journey.
